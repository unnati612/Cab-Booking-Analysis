# Cab Booking Data Analysis using SQL

This project focuses on analyzing a cab booking system using SQL to extract meaningful insights related to bookings, customers, drivers, and revenue. The database is designed to simulate a real-world cab service platform and supports analytical querying for decision-making.

## Project Objective
The main goal of this project is to perform structured data analysis using SQL by designing a relational database and running analytical queries to understand booking patterns, demand trends, and revenue distribution.

## Dataset Overview
The project includes multiple interrelated tables representing a cab booking system, such as:
- Customers
- Drivers
- Cab details
- Trip bookings
- Payment information

The data is created using SQL insert statements to closely resemble real-world operational data.

## Database Design
- Relational database schema with proper primary and foreign keys
- Normalized tables to avoid redundancy
- Logical relationships between customers, drivers, trips, and payments

## SQL Operations Performed
- Table creation using `CREATE TABLE`
- Data insertion using `INSERT`
- Data retrieval using `SELECT`
- Filtering using `WHERE`
- Aggregation using `COUNT`, `SUM`, `AVG`
- Grouping data with `GROUP BY` and `HAVING`
- Joining multiple tables using `INNER JOIN` and `LEFT JOIN`
- Subqueries for advanced analysis

## Key Analysis & Insights
- Identified peak booking periods based on trip data
- Analyzed total and average fare amounts
- Determined high-demand routes and frequent customers
- Evaluated driver performance using trip counts and earnings
- Analyzed booking trends for better business understanding
